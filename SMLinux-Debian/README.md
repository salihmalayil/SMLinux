# SMLinux-Debian

**Status: not started.** There is no Debian code, image or release yet.

The plan is to bring the SMLinux desktop (KDE Plasma + the SMLinux look, live wallpaper
and session switching from [SMLinux-Arch](../SMLinux-Arch/0.1-current-release/README.md))
to a Debian stable base, for people who prefer slower, very stable updates.
