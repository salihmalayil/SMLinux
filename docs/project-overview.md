# Project Overview

SMLinux is a Linux operating system project currently under active development. The repository is designed to support multiple editions and a staged release model.

## Editions

- Ubuntu-based edition
- Arch Linux-based edition
- Debian-based edition

## Release flow

Each edition follows the same structure:

- 0.1 current release
- 1.0 next big release
- 2.0 future prototype

## Goals

- build a consistent Linux project identity
- support multiple base distributions
- organize development by stage and release milestone
- maintain a clean roadmap for future releases
