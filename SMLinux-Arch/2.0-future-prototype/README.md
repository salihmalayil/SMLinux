# SMLinux-Arch 2.0: future prototype

**Status: ideas only, nothing built.** These are directions to explore after 1.0, not promises.

- **SMLinux Shell:** a native Qt/QML shell (bar, dock, launcher, quick settings) replacing
  Waybar + Wofi in Hyprland, with one shared design system for both desktops.
- **Liquid glass effects:** real refraction/glass blur for panels using Hyprland's newer blur
  variants, tuned for battery life.
- **Atomic updates and rollback:** btrfs snapshots before every update, bootable from the
  boot menu.
- **First-run welcome app:** choose desktop, theme accent, wallpaper and apps on first login.
